# 12. White-Label Rebranding Guide

This software architecture is 100% white-label. Customize everything inside `.env` without modifying source code:
- `BRAND_NAME`: Sets the AI persona identity, email headers, and knowledge responses.
- `MENTORS_LIST`: Sets your academy's instructor roster.
- `SUPPORTED_PLATFORMS`: Sets supported execution platforms (`Webull, IBKR, TradingView`, etc.).
- `VIP_MONTHLY_USD`, `WORKSHOP_MEMBER_PRICE`, `WORKSHOP_NONMEMBER_PRICE`, `PRIVATE_SESSION_USD`: Controls quoted pricing across all agents.
